# 🌠 Comet 訂單查詢與回報系統

這是一個基於 **Google Apps Script (GAS)** 開發的輕量化訂單管理系統，連結 Google Sheets 作為後端資料庫，提供使用者查詢訂單狀態、查看物流資訊，以及回報匯款末五碼或託運單號的功能。

## 🚀 核心功能
- **多模式查詢**：支援多種訂單模式（匯款、集運、賣場跳轉等）。
- **雙按鈕操作**：在歷史紀錄頁面提供「查看資訊」與「快速回報」獨立按鈕，優化使用者體驗。
- **智慧記憶**：自動記錄使用者輸入過的 Email、聯絡帳號，減少重複填寫。
- **防呆機制**：
  - 匯款末五碼必須為 5 碼數字。
  - 韓國託運單號必須為 12 碼數字。
- **UI 優化**：
  - 採用 Tailwind CSS 打造精美卡片式介面。
  - 支援 Modal 層級優化（Z-index），確保視窗彈出時不會互相遮擋。

## 🛠️ 技術棧
- **Frontend**: HTML5, Tailwind CSS, JavaScript (Vanilla JS)
- **Backend**: Google Apps Script
- **Database**: Google Sheets

## 📂 檔案架構
- `Code.gs`: 處理後端邏輯、Google Sheets 讀寫及 Email 發送。
- `Index.html`: 系統主介面、CSS 樣式及前端互動邏輯（JavaScript）。

## ⚙️ 安裝與部署
1. 將 `Code.gs` 與 `Index.html` 貼入 Google Apps Script 專案。
2. 於 `Code.gs` 中設定 `ADMIN_EMAIL` 與 `API_KEY`。
3. 部署為 Web App，並將網址提供給使用者。

## 🀄 台灣麻將記帳系統

`mahjong-scorekeeper/index.html` 是一個獨立的靜態網頁小工具，用於朋友間打麻將時記帳算錢。介面分成五個分頁（本局／戰績／月曆／名單／設定），底部有大按鈕的頁籤列。

- **本局**：開局先在「名單」設定「我」，接著只需快選 3 位常用對手（或新增），系統會自動隨機抓位排出東南西北，可用 ▲▼ 或「點兩人互換」調整座位，坐東的是第一位莊家。
- **手勢記分**：長按胡牌者卡片拖曳到放槍者卡片＝放槍；卡片點三下＝自摸；點卡片上的門風圈圈＝換莊家。台數在上方用大按鈕/快選數字先設定好，再用手勢套用到對應玩家。也有「刪除上一筆」可修正誤觸。
- **「將」的概念**：一場牌局可以打好幾「將」——一將打完可以選「還沒打完繼續記」「再開一將（重新抓位，錢繼續累加到同一場）」或「結束整場並結算」；只有結束整場才會列入戰績。
- **計算邏輯**：放槍由放槍者賠贏家；自摸可選「三家各付全額」（胡牌者收三倍，預設）或「三家均攤」（三家平分同一筆總額）。莊家連莊加成公式為 2n+1 台（上莊 +1、連一 +3、連 n 則 +2n+1），且只在「閒家自摸」時自動套用；莊家自己胡牌、放槍、被自摸等情況都不自動加成，台數請自行輸入（可用「莊家台」開關手動關閉自動加成）。
- **戰績**：長期統計（各玩家總場次/淨輸贏）、門風（依東南西北統計「我」的輸贏，逐手計算以正確反映換位/重新抓位）、歷史牌局（可展開查看每手明細）、分析（自摸/放槍/當莊時贏在哪輸在哪）——只統計已結束的牌局。
- **月曆**：月曆檢視每天「我」的輸贏（綠贏紅輸），可點日期查看當天紀錄或補記過去的牌局。
- **名單**：常用對手（標星號常用、設「我」用於開局自動入座與統計、改名、刪除）與常用場地，開局時可快速帶入。
- **設定**：預設底/台金額、雲端同步狀態、清空所有資料。
- 純 HTML/CSS/JavaScript，無需安裝，直接用瀏覽器開啟 `mahjong-scorekeeper/index.html` 即可使用，適合手機觸控操作。
- **雲端同步**：透過發布為 Claude Artifact 開啟時，每次操作都會即時同步到雲端，任何裝置打開同一個網址都會看到最新資料；若不是透過該網址開啟（例如直接下載此檔案在本機打開），則自動退回只存在瀏覽器 `localStorage`（僅該裝置本機保存）。舊版資料格式（單一連續帳本、或沒有「將」分層的版本）都會自動搬移到新格式，不會遺失。
